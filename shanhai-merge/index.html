山海合成怎么玩

目标：把上古神兽两两合体，合成出目标阶（默认九尾狐）即获胜；最高可合到饕餮（八阶）。

  1. 怎么合：拖动一只神兽到同阶的另一只身上，两只合体成高一阶（山魈+山魈=白泽，以此类推）。也可以先点一只、再点另一只。
  2. 飘落：每次合成后天上会飘落 1~2 只新神兽，只落在空位上；合成次数越多，飘得越快。
  3. 结束：棋盘塞满又合不动，或者步数挑战用完步数，本局就结束。
  4. 撤销：任何一步都能撤销 —— 合成类游戏没有撤销很痛苦，按「撤销一步」就回去了。
  5. 每日固定局：按日期派生的种子，当天所有人的初始盘面和整条飘落序列完全一样，可以直接比分数。

八阶神兽：山魈 → 白泽 → 玄鸟 → 毕方 → 九尾狐 → 烛龙 → 鲲鹏 → 饕餮
