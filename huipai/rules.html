回牌 · 规则

  • 人数：3 人
  • 牌：3 副共 156 张（含 6 张大小王）
  • 开局：每人 10 张，余 126 张作牌堆；首局随机定首出，此后由上一局第一个出完者先出

基本牌型

  • 单张
  • 对子
  • 三张
  • 三带一
  • 三带二
  • 顺子(≥5,3→A,不含2与王)
  • 连对(≥3对)
  • 飞机(连续三张+等量单/对)
  • 四带二
  • 炸弹(≥4张同点)
  • 王炸(六张王)

特殊牌型

  • 5-10-K：5、10、13 各一张共 3 张，三张必须同一手出，不得拆开混入其他牌型

牌力阶梯（从小到大）

四炸 < 异色5-10-K < 五炸 < 方片5-10-K < 六炸 < 梅花5-10-K < 七炸 < 红桃5-10-K < 八炸 < 黑桃5-10-K < 九炸 < 十炸 < 十一炸 < 十二炸 < 王炸(六王)
  • 花色强弱：♦=1 < ♣=2 < ♥=3 < ♠=4
  • 异色档；对应花色档；异色档
  • 同档5-10-K相遇视为平手，先出者压住
比较与点数
  • 点数：3<4<…<A<2<小王<大王
  • 同牌型才可比，跨牌型不可比；炸弹与5-10-K之间只按牌力阶梯比，不用点数比
补给 / 洗牌 / 胜负
  • 补给：第 1 名 6 张，其余各 3 张
  • 洗牌：牌堆抽空则弃牌洗回，最多 3 次；牌堆抽空则弃牌洗回；用尽后不再补给，只用手牌打完
  • 胜负：先出完手牌者胜，名次按出完顺序
  • 和棋：无；计分：不计局分（只记名次与洗牌次数）
边缘细则
  1. 顺子/连对/飞机不得含2与王；顺子最长3→A共12张
  2. 飞机带翅膀必须连续三张各带同数量，三带一与三带二不混用
  3. 5-10-K三张必须同一手出，不得拆散
  4. 炸弹与5-10-K之间只能同档互压，不能用点数比
